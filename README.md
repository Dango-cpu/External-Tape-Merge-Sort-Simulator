# External-Tape-Merge-Sort-Simulator
This project simulates sorting large datasets that cannot fit entirely into main memory, inspired by sequential tape merging techniques. It implements an external sorting algorithm that reads large files in fixed-size chunks, sorts them in-memory, and writes them to temporary disk-based 'runs'. These runs are then combined using a k-way merge. The simulator features at least two simulated 'tapes'/streams and includes detailed performance tracking to measure the number of passes and total I/O (bytes read and written) based on varying file sizes, memory buffer limits, and merge orders
